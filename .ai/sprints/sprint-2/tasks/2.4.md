## Design Decisions

- **D-1 Evidence contract** — `validateEvidence` requires `ai_assisted` as a boolean and holds `ai_tool`, when present, to a string with a letter or digit, only on an assisted record. Malformed provenance is 422 `rejected` with no `policy_id`; assisted with no tool is 422 `needs-remediation` with `policy_id` (FR-3.1 literally).
- **D-2 Evaluator** — the version gate reads `GUARDRAIL_SCHEMA_VERSION`; the provenance rule is fail-closed (applies unless a policy says `false`, which the validator refuses); a `rules` that is not an object, or a list rule that is not a list, is `rejected` as an unsupported policy (S-1, N2-2) rather than read as "no rule".
- **D-3, D-4 `guardrails/0`, closed** — `validateGuardrailPolicy` in `packages/contracts/src/schema.mjs`: closed at every level, approval complete with calendar-valid UTC timestamps, approval text with a letter or digit and no surrounding whitespace, a placeholder rule over whole ASCII tokens (`example`, `tbd`, `todo`, `xxx`, … plus `n/a`, `<`/`>`), every rule typed, the provenance rule fixed at `true`. The closed schema is the **second NFR-1.1 exception** (the first: 2.1's `workload_identity`), recorded in `docs/contracts.md`.
- **D-5 Callers** — `main.mjs` loads the policy at module scope through `loadGuardrailPolicy()` and refuses to start; `createRequestHandler` refuses to be built; both hold a `structuredClone`d, deep-frozen copy (N-3, N2-1), so what was checked is what runs.
- **D-6, D-7 Decision record and conformance test** — `config/control-plane/decisions/POL-0001.md`; `tools/sdlc-controls/policy-conformance.test.mjs` P1–P9 holds the shipped file, the validator, the evaluator's rule reads, `docs/contracts.md` and the record together, uncached in `test:controls`.
- **D-9** — `openapi.json` 0.3.0 → 0.4.0 once: `ai_assisted` required, provenance and `policy_id` described as what is enforced, "traceable to the human approval" removed.
- **D-10** — `contracts.md`, the threat model (MIT-11/12 `in place`, RR-3/8/9 successors, ABU-9/10 re-measured over a real socket, TB-2/TB-3, Findings 6 and 9) say what is enforced, and stop.
- **N-12 / M-1, corrected brief** — at `6b489ff` the "no reason speaks of verification" probe already failed when either rule was deleted. After D-2's fail-closed default it no longer catches a `blocked_tiers` deletion; the named test does (Phase ⑤).

## Human Interventions

- **Phase ① gate**: the agent counted 22 handoffs and 6 defects under a 3 SP row → the founder approved the re-estimate to 5 SP, no split. — **Lesson**: as in 2.1 and 2.2, count what the ADRs, the threat model and measurement hand a task before accepting its row.
- **Phase ① gate, Q-1 approval**: the agent asked the founder for "the real approval record" → the founder asked "why do you need me", "is this a fiction decision", "shall we use an existing ADR", "your reco?"; the agent explained that an approval written by the AI would recreate ABU-10, that no existing ADR approves these rules, and that the record file is the decision document, and recommended values → the founder approved "POL-0001 as recommended", and the agent typed the files. — **Lesson**: for a solo founder an approval is the founder's explicit yes recorded in a signed commit; explain that up front and offer concrete values, rather than asking for a decision document the founder does not have.
- **Phase ④ cycle 1, B-1**: the orchestrator shortened the sub-agent's verified C5 message into an overclaim ("unapproved", "real approval") → caught by review, reworded by rebase. — **Lesson**: a commit message rewritten by the orchestrator is a new claim and must be re-checked against the diff; never compress a verified message without re-verifying it.
- **B-1 reword, `/tmp`**: the agent put the reword message file in `/tmp` → the founder: `/tmp` is not part of the project → `.git/C5_MSG`. — **Lesson**: helper files for the founder's commands go inside the repository's `.git/`, never system temp.
- **B-1 reword, bullet capitalisation**: the founder asked for body bullets to start with a capital unless they open with an identifier → C5 reworded again; made a standing rule. — **Lesson**: body bullets are capitalised unless they open with an identifier or file name.
- **Phase ④ cycle 2 / ⑤**: the founder chose to fix the optional Nits N2-1, N2-2 and the Low F-1 rather than record them. — **Lesson**: an optional finding whose fix is one small, tested change is cheaper to close than to carry; offer the fix with its size.
