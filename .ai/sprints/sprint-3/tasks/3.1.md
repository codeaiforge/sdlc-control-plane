## Design Decisions

- **D-1 Adapter** — `packages/evidence-adapter/src/submit-evidence.mjs`, `node:` imports only. Mints a fresh token per attempt for `urn:codeaiforge:sdlc-control-plane:production`, sends the gate's `evidence.json` byte for byte. Exit 0 accepted, 1 not accepted (422), 2 local refusal, 3 no record, 4 refused or an answer it does not handle, 5 unavailable after retries.
- **D-2 Transport** — `https.request`, `rejectUnauthorized: true`, `agent: false`, no redirects; plain HTTP only to literal `127.0.0.1`/`[::1]`; caps of 1 MiB (record, checked before minting), 8 KiB (token) and 64 KiB (answer).
- **D-3 Retries** — only 429, 502–504, a POST timeout or network error (a lost answer), and `mint-unavailable` (the runner's token endpoint answered 500 or more, or not at all); 4 attempts in 150 s, backoff 1–2/2–4/4–8 s, `retry-after` honoured for 1–60 s. A 409 is never retried.
- **D-4 Output** — fixed reason codes; server echoes of the token become `[redacted]`; echoed fields have controls, line breaks and `#` escaped (no `::` or `##[` workflow command); the job summary entity-escaped; wording "self-attested", never "verified".
- **D-5 Endpoint a constant** (Q-10) — an input would let a same-repository writer send a token carrying the pinned claims to their own server and replay it for 300 s. Every run exits 2 until a reviewed commit sets it.
- **D-6 Reusable workflow** — `.github/workflows/submit-evidence.yml`: `workflow_call`, no inputs or secrets, `permissions: {}`; one job with `id-token: write` + `contents: read`, `if: ${{ !cancelled() && github.server_url == 'https://github.com' }}`; checks out `codeaiforge/sdlc-control-plane` (literal) at `${{ job.workflow_sha || 'job-workflow-sha-missing' }}`, sparse to the one file; actions pinned by SHA (checkout v6.1.0, setup-node v6.5.0, download-artifact v6.0.0); the artifact downloaded after the code, as data.
- **D-7 Shape held by test** — `tools/sdlc-controls/evidence-adapter-conformance.test.mjs` holds the workflow exactly (every key, step, `with:`, `run:`, pinned action), refuses 30 named edits, and reads it with a strict YAML subset that refuses CR, U+2028 and other non-space whitespace. It also holds the audience and byte caps equal to the control plane's.
- **D-8 Nx** — one new edge, `control-plane-api → evidence-adapter`, from the E2E test only; `REVIEWED_FAN_IN` gains `'evidence-adapter': 1`, `contracts` stays at 2.
- **D-9 No ADR** — four wording deviations from ADR-0003 are recorded in `docs/contracts.md`: the raw runner protocol in place of `core.getIDToken`; the measurements moved to 3.3; per-run change ids against "first record stands"; the endpoint as a constant.
