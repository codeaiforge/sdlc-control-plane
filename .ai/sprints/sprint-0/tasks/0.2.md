## Design Decisions

- Three schema versions are exported as constants (`evidence/0`, `workspace-registry/0`, `guardrails/0`) so every consumer compares against one definition rather than a literal.
- Validation is hand-rolled with no dependency. The contract boundary is the one place a library version bump would become a governance event.
- Validators collect all errors and return `{ ok, errors }` rather than throwing on the first. A workspace submitting bad evidence gets a complete remediation list in one response.
- Only the required subset is checked. Unknown fields pass untouched, which is how NFR-1.1's additive-field tolerance is satisfied — and why the production persistence adapter, not the validator, owns preserving them.
